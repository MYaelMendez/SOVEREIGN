PHASE 1: PARTICLE FIELD

Initial 90,000 particles rendered as a deterministic torus field
using mulberry32(seed=1517) for stable, repeatable output.
Single PointsMaterial, single color channel.

const r = mulberry32(1517); for(let i = 0; i < 90000; i++) { const a = r() * Math.PI * 2; const rad = FIELD_RADIUS + (r() - .5) * 9; // ...position + color }

PHASE 2: FLEET WAVES

Three bot swarms introduced as waves of fleets —
hermes-agent (gold, 5000 pts), vps_node (cyan, 3000 pts),
teknium (emerald, 2000 pts) — each with distinct orbital radius.

const FLEETS = [ { name: "hermes-agent", color: 0xD4AF37, count: 5000, radius: 8 }, { name: "vps_node", color: 0x00eaff, count: 3000, radius: 12 }, { name: "teknium", color: 0x00ff9d, count: 2000, radius: 10 } ];

PHASE 3: SHADER ORCHESTRATION

Upgraded from PointsMaterial to ShaderMaterial
with GPU-driven wave functions. Each fleet gets its own
phase offset, wave amplitude, and pulse via uniforms.

uniform float u_time; uniform float u_phase; vertexShader: float wave = sin(u_time * (0.3 + u_phase * 0.1) + fleetId * 6.28); pos.y += wave;
