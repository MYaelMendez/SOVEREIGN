## tinyCUDA as a verifier

The innovation is not the raster technique — it is what determinism enables.
A byte-identical render is a gradeable assertion: `tinycuda grade` returns
reward 1.0/0.0, zero tokens, zero model calls. It catches the white-silhouette
class that every unit test passes.

Two properties found by testing, not assumed:
- **Sensitivity floor.** A 0.5 mm edit renders identically at 120×160. Reward
  now requires pixel match AND unchanged asset; sub-pixel edits are reported.
- **Shape, not pose.** `fit_camera` normalises translation and scale. Scale ×2
  is exact in float32; translate +0.5 rounds and flips pixels.
