Verdict
Worth a repo? Yes — as spec, not implementation.
The schemas are language-agnostic, zero-dependency, and immediately usable by any agent fleet. They are the data shapes of sovereign computing — the contract between agent and system.

What makes them valuable is not the code (13KB) but the pattern: every agent declares capabilities, every action produces a receipt, every artifact passes a gate. That pattern is what Teknium would adopt — folded into Hermes, not shipped standalone.
